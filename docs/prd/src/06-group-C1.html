10Screens and User Experience

The resident and administrator use the mobile app (screens S-xx). Guests use a browser page (W-xx) that needs no install. Where deep links are delivered (Could), a registered guest sees the same invitation inside the app (S-11). The administrator uses the same app as residents, with an extra "Community" area for approvals and the simulator. Screens retired in v2.0 (S-07 wizard, S-09 community log) are listed in Section 7.6. Language: Hebrew UI with right-to-left layout as the primary language, and English as a Could (NFR-17).

What it shows: the main path through the screens in the table above. A resident signs in and creates a permission, either with the form or by describing it in words and reviewing the AI draft in the same form. They then share the link. The guest opens it in a browser and requests an opening. Opening it in the app through a deep link is a Could, shown dotted. A grant shows up in the resident's Activity screen. Why it matters: it confirms that the guest's path from link to opening is a single page with one tap (G4), and that the screen IDs match the table and the wireframes.
RTL and accessibility rules for all screens (NFR-15, NFR-17):
  • Layout mirrors for Hebrew. URLs, phone-style numbers, times and counters stay left-to-right isolated inside RTL text.
  • Weekday chips run Sunday→Saturday (א׳–ש׳), right to left, each with a full spoken label ("Tuesday").
  • Every touch target, including Approve and Reject, is at least 48×48 dp.
  • Text contrast is ≥ 4.5:1, including disabled-state labels, and is checked for outdoor readability.
  • Status always pairs an icon or colour with a text label.
  • W-01 announces state changes ("Opening…", "Gate opening", the reason) through a live region for screen readers.

About the wireframes: they are low-fidelity sketches in grayscale with no visual design. They show only what sits where on each screen. The final UI will be Hebrew, right-to-left. These sketches are drawn left-to-right in English so the PRD reads consistently.
