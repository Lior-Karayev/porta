# Sprint Carryover Log

A permanent record of every sprint commitment that was **not completed** by the end of its sprint. Sprints end on their planned date. Unfinished work is never silently moved, extended or marked as complete.

**Rules**

- Add an entry on the sprint's last day for every commitment that is not `DONE`.
- Never delete or rewrite an earlier entry. If the plan changes again, add a follow-up line under "Team decision" with the date.
- The team decision is made by humans. An agent may propose a decision, but records it as *Proposed* until a human approves it.

## Entry template

```markdown
### CO-<sprint>-<n> · <short title> (Issue #…)

| Field | Value |
|---|---|
| 1. Original task and goal | … (sprint goal it served) |
| 2. Work completed | … (PRs, commits) |
| 3. Remaining work | … |
| 4. Why it was not finished | … |
| 5. Blockers and dependencies | … |
| 6. Impact on future work | … (which later tasks or milestones are affected) |
| 7. Recommended next step | … |
| 8. Responsible contributor | A / B / C |
| 9. Team decision | Carry over to Sprint N+1 · Reduce scope · Drop — decided by <name>, YYYY-MM-DD (D-xx if significant) |
```
